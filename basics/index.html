컴퓨터 기초

🧸 비유

dbt 는 자동차의 운전대입니다. 운전대만 알아도 운전은 됩니다. 그런데 경고등이 켜지면 엔진(CPU · 메모리), 연료 라인(네트워크), 정비 기록(git)을 아는 사람만 원인을 찾습니다. 이 코스는 정비사가 되자는 게 아니라, 경고등이 무슨 뜻인지 아는 운전자가 되자는 코스입니다.

여덟 장

    심화 · 4장 다음에 컴퓨터끼리 대화하는 법 — API · REST의 역사: 소켓 → RPC → SOAP → REST → GraphQL · gRPC, REST · RESTful · REST API 구분, 요청-응답 · 폴링 · 웹훅 · 스트리밍, 광고 매체 · BigQuery · Cube · Metabase가 각각 어떻게 대화하는지.
    API 호출 실전 — 공공데이터포털로 처음부터 끝까지: 키 발급 · Encoding/Decoding 키 함정 · 응답 봉투 구조 · 에러 두 층(HTTP 상태와 resultCode) · 페이지 넘기기 · 재시도 · 멱등 저장, 키 없이 연습하는 모의 서버, 공공 API vs 광고 매체 API(OAuth · 서명 · 커서 · 비동기 리포트).
