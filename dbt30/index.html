하루 진행 방식

  ① 학습 목표 → ② 핵심 개념 → ③ 아키텍처 → ④ 실무 사례 → ⑤ 코드 예제
                                                              │
  ⑩ 다음 예고 ◀ ⑨ 완료 조건 ◀ ⑧ 퀴즈 5문제 ◀ ⑦ 코드 리뷰 ◀ ⑥ 직접 구현
  • 코드는 직접 씁니다. 정답은 먼저 보여 주지 않습니다. 실습 단계에는 힌트만 있습니다.
  • 코드 리뷰는 Claude Code에 제출합니다. "dbt 30일 Day N 제출"과 프로젝트 경로를 알려 주면 리뷰합니다. 실행 성공보다 유지보수성·확장성을 봅니다. 설계가 잘못되면 그대로 지적합니다.
  • 완료 조건을 못 채우면 다음 Day로 넘어가지 않습니다. 완료 버튼은 스스로 정직하게 누릅니다.
  • Day 7 · 14 · 21 · 30에 주간 평가를 하고, 부족한 부분은 다음 주 시작 전에 보충합니다.
