# 필수 정리 — 콘텐츠 편집 안내

화면(HTML·JS)과 콘텐츠를 분리해 두었습니다. 내용을 고칠 때는 아래 파일만 수정하면 됩니다.

| 파일 | 무엇 |
|---|---|
| `curriculum.json` | 주차 제목, Day 번호·제목·한 줄 요약 (목차 카드에 표시) |
| `days/dayNN.md` | Day 본문 (예: `days/day07.md`) |
| `schema/*.sql` | 한빛제약그룹 공통 스키마(PostgreSQL DDL + 샘플 INSERT). Day 예시 SQL은 이 위에서 실행 |
| `WORLD.md` | 가상 그룹사 "한빛제약그룹" 세계관·표준 약어·공통 샘플 데이터 |

화면 코드: `index.html`(목차), `day.html?d=N`(상세), `../assets/essentials.js`(렌더러), `../assets/style.css`(맨 아래 "필수 정리" 블록).

로컬에서 볼 때는 파일을 직접 열지 말고 서버로 여세요(본문을 fetch 로 읽기 때문):

```
cd de-study
python -m http.server 8004
# http://localhost:8004/essentials/
```

## Day 본문 템플릿

모든 Day는 아래 순서의 `##` 제목을 씁니다. 첫 줄 `# 제목`은 화면에 표시되지 않습니다(제목은 curriculum.json 에서 가져옴).

```
# Day N. 제목
## 오늘의 한 줄
## 왜 중요한가
## 핵심 개념
### 개념 1 ...
## 예시
## Before / After
## 시니어는 이렇게 판단한다
## 흔한 실수 3가지
## 셀프 체크 질문
## 오늘의 과제
## 실무 산출물 연결
## 참고할 원전
```

## 지원하는 마크다운 문법 (외부 라이브러리 없이 직접 렌더링)

| 문법 | 결과 |
|---|---|
| `## 제목`, `### 소제목` | 제목 (`##` 은 왼쪽 목차에 나옴) |
| 빈 줄로 구분된 문장 | 문단 |
| `- 항목`, `1. 항목` | 목록 (한 단계만, 들여쓴 다음 줄은 같은 항목에 이어짐) |
| `\| 머리 \| 머리 \|` + `\|---\|---\|` + 행 | 표. 셀 안의 `\|` 는 `\\|` 로 |
| ```` ```sql 파일명(선택) ```` … ```` ``` ```` | 코드 블록 (복사 버튼, 가로 스크롤) |
| ```` ```text ```` 또는 ```` ```erd ```` | 텍스트 다이어그램 (ERD 등) |
| `**굵게**`, `` `코드` ``, `[링크](주소)` | 인라인 |
| `> 문장` | 테두리 상자 |
| `:::summary 제목` … `:::` | 강조 상자 (`summary`, `tip`, `warn`, `analogy`, `proc`, `note`) |
| `:::answer 버튼 문구` … `:::` | 접기(토글). 셀프 체크 모범 답안용 |
| `---` | 구분선 |

지원하지 않는 것: 중첩 목록, 이미지, HTML 직접 쓰기(글자로 보임), Mermaid.
